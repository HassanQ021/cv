# Hassan Qamar — Digital Marketing Resume

A single-page, dark calico-inspired resume website. No portrait, external fonts, analytics, cookies, build tools or third-party runtime dependencies are required.

## Preview
Open index.html in a browser. Keep styles.css and the PDF in the same folder.

## GitHub Pages
1. Create a repository and upload index.html, styles.css, the PDF and .nojekyll to its root. Enable hidden files when selecting .nojekyll, or create an empty file with that name in GitHub.
2. In the repository's Settings → Pages, choose deployment from a branch, then select your branch and its root folder.
3. Use the address GitHub provides after publishing. All local asset paths are relative, so the site also works under a repository path.

## Subdomain
Upload the same files to your subdomain's web root on any static website host. Point the subdomain to that host using its DNS instructions and enable HTTPS there. The exact DNS records depend on your hosting provider.

## Edit
- Profile, experience, projects and skills: index.html
- Colors, typography and responsive layout: styles.css
- Resume download: replace Hassan_Qamar_Digital_Marketing_Resume.pdf while keeping its filename, or update both download links in index.html.

## Content notes
The resume is tailored toward Digital Marketing Specialist roles using the supplied CV. Metrics are carried over from that CV, not independently verified. Project cards summarize professional engagements; the source CV did not include project URLs or visual samples. Original job titles and dates have been retained; freelance design/web work is grouped and the earlier end date for web development is stated.

The site displays the phone number, email and LinkedIn address from the original CV. Publishing the folder will make these details available to visitors. No contact form or account setup is required.
